# 개인 스킬 (Personal Skills)

직접 작성하는 개인 스킬을 두는 곳. 이 디렉토리의 스킬은 **모든 프로젝트에서** `/스킬명` 으로 호출된다.

플러그인으로 설치한 스킬(`mattpocock-skills:*` 등)은 `~/.claude/plugins/` 아래에 있고
`.gitignore`로 제외되어 있다 — 여기는 git으로 추적되는 직접 작성분 전용이다.

## 디렉토리 구조

```
skills/
  스킬이름/
    SKILL.md        # 필수. 프론트매터 + 본문
    reference.md    # 선택. 본문에서 참조하는 보조 문서
    scripts/        # 선택. 스킬이 실행하는 스크립트
```

디렉토리 이름이 곧 호출명이 된다 (`skills/deploy-check/` → `/deploy-check`).

## SKILL.md 형식

```markdown
---
name: 스킬이름
description: 언제 이 스킬을 써야 하는지 한 문장. 모델이 이 설명만 보고 호출 여부를 판단하므로 트리거 상황을 구체적으로 적는다.
---

# 스킬 제목

여기에 모델이 따라야 할 절차를 쓴다.
```

`name`은 디렉토리 이름과 일치시킨다. `description`은 "무엇을 하는지 + 언제 쓰는지" 두 가지를 모두 담아야
모델이 적절한 시점에 자동으로 불러온다.

## 작성 팁

- 설명이 아니라 **지시문**으로 쓴다. ("~할 수 있다" ❌ / "~하라" ⭕)
- 스킬 본문이 길어지면 별도 파일로 빼고 본문에서 경로로 참조한다.
- 스킬 작성 자체를 도와주는 `mattpocock-skills:writing-for-agents` 스킬이 이미 설치돼 있다.

## 참고

- 프로젝트 전용 스킬은 해당 저장소의 `.claude/skills/` 에 둔다 (여기가 아님).
- 슬래시 커맨드(`commands/`)와의 차이: 커맨드는 단순 프롬프트 치환, 스킬은 모델이 상황을 보고 자동 호출.
